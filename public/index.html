Authentication

Game Server API calls use your API key in the x-api-token header. Dashboard requests use a JWT. Manage and copy your key from Account.

1. Create a Game Room

Creates a Ludo game room and deducts the request cost from your balance.

Endpoint: POST /api/create-room Headers: Content-Type: application/json x-api-token: <Your_API_Key> Body: { "call_back": "https://your-webhook-url.com", "entry_fee": 100, "winning_prize": 500, "waiting_time": 60, "room_type": "public", "uid": "unique-id-123", "playerName": "Player1", "avater_url": "https://example.com/avatar.jpg" }

Slot reservation: If uid is passed, a slot is reserved for that player. Public matchmaking pairs into matching waiting rooms when possible.

2. Join a Game Room (WebSocket)

Connect via Socket.IO and emit joinRoom. Joining does not require an API token.

Connection: ws://your-server-domain:3000 Event: joinRoom Payload: { "roomId": "123456", "uid": "unique-id-123" }

3. Flutter Client Integration

Launch the Ludo app from Flutter with LudoKing.joinMatch().

import 'package:ludo_king/ludo_king.dart'; await LudoKing.joinMatch( uid: "unique-id-123", roomId: "123456", baseUrl: "http://your-server-domain:3000", );
